## 🗂 資料夾用途
| 資料夾 | 放什麼 |
| --- | --- |
| `00-inbox` | 還沒分類的速記，定期清空 |
| `10-projects` | 有明確結束點的專案，一案一資料夾 |
| `20-areas` | 沒有結束點的長期責任領域 |
| `30-resources` | 知識庫、參考資料、學習筆記 |
| `40-archive` | 已結束／擱置的東西 |
| `50-daily` | 每日筆記 |
| `60-meetings` | 會議紀錄 |
| `70-maps` | 心智圖（Canvas）與 MOC 索引 |
| `90-templates` | 筆記模板 |
| `99-bases` | Bases 資料表檢視 |

## 🏷 檔名 Emoji（領域）
| | `domain` | 意思 |
| --- | --- | --- |
| 🌐 | `network` | 網路／設備／維運系統 |
| 🤖 | `ai` | AI／Agent／MCP／LLM 應用 |
| 🖥 | `platform` | 平台或系統開發 |
| 📊 | `data` | 報表、資料分析、儀表板 |
| 🧰 | `tool` | 工具、腳本、CLI |
| 🧪 | `lab` | 實驗場、POC |

以上**六個都是程式碼專案**（`kind: code`）。非程式碼：📐 計畫 ｜ 💡 靈感 ｜ 📚 研究
其他筆記：🗣 會議 ｜ 📌 需求 ｜ ⚖️ 決策 ADR ｜ 🗺 心智圖
